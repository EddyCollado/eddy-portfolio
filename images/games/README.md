## Where to Find Box Art:

### Best Sources:
1. **The Cover Project** - https://www.thecoverproject.net/
   - High quality scans of original box art
   - Organized by console

2. **MobyGames** - https://www.mobygames.com/
   - Search game name → Click "Covers" tab
   - Download front cover

3. **IGDB** - https://www.igdb.com/
   - Search game → Right-click cover → Save image

4. **SteamGridDB** - https://www.steamgriddb.com/
   - Great for modern games
   - Multiple art styles available

### Quick Search Tips:
- Google: "[Game Name] box art high resolution"
- Add console name for specific versions (e.g., "Chrono Trigger SNES box art")
- Look for 300+ DPI images for best quality

## Image Guidelines:
- Format: JPG or PNG
- Recommended size: 264x352px (3:4 ratio)
- Keep file sizes under 500KB for fast loading
- Use original box art for authenticity

## Fallback:
